Simple Calculator

A Simple Calculator is a command-line Python application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The program accepts user input, processes the selected operation, and displays the result instantly.

Features

Addition, Subtraction, Multiplication, and Division

User-friendly menu-driven interface

Handles invalid inputs

Prevents division by zero errors

Allows repeated calculations


Technologies Used

Python

Command Line Interface (CLI)


How to Run

1. Install Python on your system


2. Save the file as calculator.py


3. Open terminal or command prompt


4. Run the program using:



python calculator.py

Example Output

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Clear
6. Exit
